# FinHouse Web (PWA)
App estático: roda só no navegador, sem servidor. Dados ficam no aparelho (localStorage); senha com PBKDF2-SHA256.

## Publicar no GitHub Pages (grátis)
1. Crie um repositório e envie estes arquivos na raiz.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
3. Abra `https://SEU_USUARIO.github.io/NOME_DO_REPO/` no Chrome do Android.
4. Menu ⋮ → **Instalar app** (ou *Adicionar à tela inicial*).

## Levar os dados do PC
No FinHouse de PC: Backup e segurança → Exportar JSON. No celular: aba Backup → Importar JSON.
